# Synqvero — Official Website

> **Intelligence that works in sync.**  
> *"Your problem. Our intelligence. In sync."*

Production-quality company website for **Synqvero**, an AI and technology company building practical intelligent software for real-world problems.

---

## Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React + Custom SVG
- **Graphics**: HTML5 Canvas (Dual Lemniscate Flow & Particle Physics)

---

## Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

---

## Structure
- `src/components/InteractiveSync.tsx`: Original Canvas dual-loop synchronization visualizer (`PROBLEM ↕ INTELLIGENCE`).
- `src/components/IntelligenceStack.tsx`: The Synqvero Intelligence Stack architecture diagram.
- `src/components/ProjectsShowcase.tsx` & `ProjectModal.tsx`: Real deployed AI systems showcase with deep-dive technical modals.
- `src/data/`: Structured, verifiable datasets for capabilities, projects, architecture layers, and company roadmap.
